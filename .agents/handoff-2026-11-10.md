## 3. Windows tool traps

- Most repo files use CRLF. Check with `file <path>`. `sed -i` in Git Bash converts CRLF to LF: do not use it on repo files. Use the Edit tool or Python bytes I/O.
- The Write tool writes LF. Convert new files to CRLF when the neighbours are CRLF.
- Backslashes in heredoc Python scripts can arrive collapsed. Build them with `chr(92)` and check with `od -c`.
- `git show branch:.agents/...` fails in Git Bash (path conversion). Set `MSYS_NO_PATHCONV=1`.
- A session in a worktree cannot write to the main checkout (a hook blocks it).
