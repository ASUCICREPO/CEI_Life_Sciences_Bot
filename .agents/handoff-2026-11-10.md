## 3. Windows tool traps (learned in this session)

- Most repo files use CRLF. Check with `file <path>`.
- `sed -i` in Git Bash converts CRLF to LF. Do not use it. Use the Edit tool or Python bytes I/O.
- The Write tool writes LF. Convert new files to CRLF when the neighbours are CRLF.
- Backslashes in heredoc Python scripts can arrive collapsed. For regex or escape text, build backslashes with `chr(92)` and check the bytes with `od -c`.
- `git show branch:.agents/...` fails in Git Bash (path conversion). Set `MSYS_NO_PATHCONV=1`.
- Subagents often write commit subjects longer than 5 words. Count the words BEFORE you merge. To fix them, cherry-pick and amend the message.
- Check each subagent branch for: base commit, file scope, UTF-8 (`iconv -f UTF-8 -t UTF-8`), CRLF kept, subject length, no attribution.
- Subagents can stall ("no progress for 600s"). Tell them to commit early.
- A session in a worktree cannot write to the main checkout (a hook blocks it). Work in the worktree, then merge.
